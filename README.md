MyBase

MyBase adalah aplikasi database pribadi untuk Android yang memungkinkan pengguna membuat, mengelola, menghubungkan, mengolah, dan memvisualisasikan data secara fleksibel — sepenuhnya dengan pendekatan offline-first.

MyBase dirancang sebagai database builder yang menggabungkan kemampuan Library, Field, Entry, Relation, View, Filter, Formula, Automation, JavaScript, Dashboard, File Management, dan Backup dalam satu aplikasi.

«Build your own database. Your data, your structure, your way.»

⚡ Automation

💾 Offline First

MyBase dirancang sebagai aplikasi offline-first.

Data utama dapat digunakan tanpa koneksi internet.

Fitur offline mencakup:

- Membuat Entry
- Mengedit Entry
- Menghapus Entry
- Search
- Filter
- Sort
- Relation
- Formula
- View
- Dashboard
- File lokal
- Automation yang tersedia secara offline

Internet tidak diperlukan untuk penggunaan database utama.

---

🔐 Data & Privacy

MyBase dirancang dengan prinsip:

«Your data belongs to you.»

Data lokal tidak membutuhkan server online untuk penggunaan database utama.

MyBase berfokus pada:

- Local-first data
- Offline access
- User-controlled storage
- Backup lokal
- Export data
- Restore data

Fitur online atau sinkronisasi, apabila digunakan, harus bersifat opsional dan tidak menjadi persyaratan untuk menjalankan database lokal.

🚀 Development

Clone repository:

git clone https://github.com/USERNAME/MyBase.git

Masuk ke directory:

cd MyBase

Kemudian buka proyek menggunakan Android Studio.

Build project:

./gradlew assembleDebug

APK debug akan tersedia pada:

app/build/outputs/apk/debug/
